Here's the full project code. Two design decisions I made while implementing (flagging both explicitly, since they weren't fully settled in the plan):

1. **The deployed cell fault model uses the sanitized RAN-only feature set** (no `availability_mean`, no region dummies, no cross-layer backhaul/core context) — this matches the model you already validated as the honest one (PR-AUC ~0.69), and it keeps the API stateless: a request only needs *that cell's own* recent history, not a live join across backhaul/aggregation/core telemetry the API doesn't have access to.
2. **Anomaly detection needs a short recent window (not just one value)** to apply the same persistence rule (flag only after 2+ consecutive breaching hours) statelessly, since there's no server-side history to check against between requests.

## `ml_pipeline/features.py`

```python
import numpy as np
import pandas as pd
from ml_pipeline.config import (
    LAG_HOURS, ROLLING_WINDOW_HOURS, ALARM_TRAILING_WINDOW_HOURS, NO_ALARM_SENTINEL_HOURS,
    CONGESTION_LAG_HOURS, CONGESTION_ROLLING_24H, CONGESTION_ROLLING_7D, CONGESTION_SLOPE_14D,
)


def rolling_slope(values):
    """Linear trend of a trailing window. Returns NaN if fewer than 2 finite points."""
    y = np.asarray(values, dtype=float)
    valid = np.isfinite(y)
    if valid.sum() < 2:
        return np.nan
    x = np.arange(len(y))[valid]
    return np.polyfit(x, y[valid], 1)[0]


def _hours_since_last_alarm(alarm_counts):
    """Sentinel-based: 'never alarmed' -> NO_ALARM_SENTINEL_HOURS, not 0. Conflating the
    two (as an earlier version of this pipeline did) makes 'just alarmed' and 'never
    alarmed' numerically identical, corrupting any recency-based feature."""
    result = np.full(len(alarm_counts), float(NO_ALARM_SENTINEL_HOURS))
    last_idx = None
    for i, c in enumerate(alarm_counts):
        if c > 0:
            last_idx = i
        elif last_idx is not None:
            result[i] = i - last_idx
    return result


def build_batch_cell_fault_features(hourly_ran_df):
    """Vectorized, per-cell-group feature builder for the historical training table.
    hourly_ran_df must have one row per (cell_id, timestamp), sorted or not (sorted here).
    Expects columns: cell_id, timestamp, prb_util_mean, sinr_mean, bler_mean, drop_rate_mean,
    availability_mean, handover_success_mean, traffic_mbps_mean, alarm_count,
    technology, band, site_type, region_name, cell_capacity_mbps.
    """
    df = hourly_ran_df.sort_values(["cell_id", "timestamp"]).reset_index(drop=True)
    g = df.groupby("cell_id")

    for lag in LAG_HOURS:
        df[f"prb_lag_{lag}h"] = g["prb_util_mean"].shift(lag)
    df["sinr_lag_1h"] = g["sinr_mean"].shift(1)
    df["bler_lag_1h"] = g["bler_mean"].shift(1)
    df["drop_rate_lag_1h"] = g["drop_rate_mean"].shift(1)

    w = ROLLING_WINDOW_HOURS
    df["prb_mean_4h"] = g["prb_util_mean"].transform(lambda s: s.rolling(w, min_periods=1).mean())
    df["prb_std_4h"] = g["prb_util_mean"].transform(lambda s: s.rolling(w, min_periods=2).std())
    df["sinr_mean_4h"] = g["sinr_mean"].transform(lambda s: s.rolling(w, min_periods=1).mean())
    df["sinr_slope_4h"] = g["sinr_mean"].transform(lambda s: s.rolling(w, min_periods=2).apply(rolling_slope, raw=True))
    df["bler_mean_4h"] = g["bler_mean"].transform(lambda s: s.rolling(w, min_periods=1).mean())
    df["drop_rate_mean_4h"] = g["drop_rate_mean"].transform(lambda s: s.rolling(w, min_periods=1).mean())

    df["prb_change_1h"] = df["prb_util_mean"] - df["prb_lag_1h"]
    df["sinr_change_4h"] = df["sinr_mean"] - g["sinr_mean"].shift(4)
    df["bler_change_4h"] = df["bler_mean"] - g["bler_mean"].shift(4)

    df["alarm_count_trailing_24h"] = g["alarm_count"].transform(
        lambda s: s.rolling(ALARM_TRAILING_WINDOW_HOURS, min_periods=1).sum())
    df["hours_since_last_alarm"] = g["alarm_count"].transform(
        lambda s: pd.Series(_hours_since_last_alarm(s.to_numpy()), index=s.index))

    df["hour_of_day"] = df["timestamp"].dt.hour
    df["day_of_week"] = df["timestamp"].dt.dayofweek
    df["is_weekend"] = (df["day_of_week"] >= 5).astype(int)
    return df


def compute_live_cell_fault_features(window_df: pd.DataFrame, static_attrs: dict) -> dict:
    """Stateless single-entity feature computation for the API. window_df: hourly rows for
    ONE cell, sorted ascending by timestamp, most recent row last. Returns a flat dict of
    features for the LATEST timestamp only — this is what gets scored.
    Requires at least 5 rows (4h of history + current) for full feature coverage; degrades
    gracefully (NaN -> later imputed) with fewer, but a fault decision on <2 rows is unreliable.
    """
    df = window_df.sort_values("timestamp").reset_index(drop=True)
    if len(df) < 2:
        raise ValueError("Need at least 2 hourly rows to compute lag/delta features.")

    latest = df.iloc[-1]
    w = ROLLING_WINDOW_HOURS

    def lag(col, n):
        idx = len(df) - 1 - n
        return df[col].iloc[idx] if idx >= 0 else np.nan

    def roll_mean(col, window):
        return df[col].tail(window).mean()

    def roll_std(col, window):
        tail = df[col].tail(window)
        return tail.std() if len(tail) >= 2 else np.nan

    def slope(col, window):
        return rolling_slope(df[col].tail(window).to_numpy())

    features = {
        "sinr_mean": latest["sinr_mean"], "bler_mean": latest["bler_mean"],
        "drop_rate_mean": latest["drop_rate_mean"], "prb_util_mean": latest["prb_util_mean"],
        "handover_success_mean": latest["handover_success_mean"],
        "sinr_lag_1h": lag("sinr_mean", 1), "bler_lag_1h": lag("bler_mean", 1),
        "drop_rate_lag_1h": lag("drop_rate_mean", 1),
        "prb_lag_1h": lag("prb_util_mean", 1), "prb_lag_4h": lag("prb_util_mean", 4),
        "prb_mean_4h": roll_mean("prb_util_mean", w), "prb_std_4h": roll_std("prb_util_mean", w),
        "sinr_mean_4h": roll_mean("sinr_mean", w), "sinr_slope_4h": slope("sinr_mean", w),
        "bler_mean_4h": roll_mean("bler_mean", w), "drop_rate_mean_4h": roll_mean("drop_rate_mean", w),
        "prb_change_1h": latest["prb_util_mean"] - lag("prb_util_mean", 1),
        "sinr_change_4h": latest["sinr_mean"] - lag("sinr_mean", 4),
        "bler_change_4h": latest["bler_mean"] - lag("bler_mean", 4),
    }

    alarm_counts = df["alarm_count"].to_numpy()
    features["alarm_count_trailing_24h"] = df["alarm_count"].tail(ALARM_TRAILING_WINDOW_HOURS).sum()
    hsla = _hours_since_last_alarm(alarm_counts)
    features["hours_since_last_alarm"] = float(hsla[-1])

    ts = pd.Timestamp(latest["timestamp"])
    features["hour_of_day"] = ts.hour
    features["day_of_week"] = ts.dayofweek
    features["is_weekend"] = int(ts.dayofweek >= 5)

    features.update({
        "technology": static_attrs["technology"], "band": static_attrs["band"],
        "site_type": static_attrs["site_type"], "cell_capacity_mbps": static_attrs["cell_capacity_mbps"],
    })
    return features


def compute_live_congestion_features(window_df: pd.DataFrame, static_attrs: dict) -> dict:
    """window_df: hourly rows for ONE cell, columns prb_util_mean, traffic_mbps_mean,
    timestamp. Requires up to MIN_CONGESTION_HISTORY_HOURS for the full feature set;
    slope/168h-lag features return NaN gracefully if history is shorter."""
    df = window_df.sort_values("timestamp").reset_index(drop=True)
    latest = df.iloc[-1]

    def lag(col, n):
        idx = len(df) - 1 - n
        return df[col].iloc[idx] if idx >= 0 else np.nan

    def roll_mean(col, window):
        return df[col].tail(window).mean()

    def roll_std(col, window):
        tail = df[col].tail(window)
        return tail.std() if len(tail) >= 2 else np.nan

    def slope(col, window):
        tail = df[col].tail(window).to_numpy()
        return rolling_slope(tail) if len(tail) >= 2 else np.nan

    features = {
        "prb_util_t": latest["prb_util_mean"], "traffic_t": latest["traffic_mbps_mean"],
        "capacity_headroom_current": static_attrs["cell_capacity_mbps"] - latest["traffic_mbps_mean"],
        "prb_lag_1h": lag("prb_util_mean", 1), "prb_lag_2h": lag("prb_util_mean", 2),
        "prb_lag_24h": lag("prb_util_mean", 24), "prb_lag_168h": lag("prb_util_mean", 168),
        "traffic_lag_1h": lag("traffic_mbps_mean", 1), "traffic_lag_24h": lag("traffic_mbps_mean", 24),
        "prb_mean_24h": roll_mean("prb_util_mean", CONGESTION_ROLLING_24H),
        "prb_std_24h": roll_std("prb_util_mean", CONGESTION_ROLLING_24H),
        "prb_mean_7d": roll_mean("prb_util_mean", CONGESTION_ROLLING_7D),
        "prb_slope_7d": slope("prb_util_mean", CONGESTION_SLOPE_14D),
        "traffic_mean_24h": roll_mean("traffic_mbps_mean", CONGESTION_ROLLING_24H),
        "traffic_slope_7d": slope("traffic_mbps_mean", CONGESTION_ROLLING_7D),
    }
    ts = pd.Timestamp(latest["timestamp"])
    features["hour_of_day"] = ts.hour
    features["day_of_week"] = ts.dayofweek
    features["is_weekend"] = int(ts.dayofweek >= 5)
    features.update({
        "technology": static_attrs["technology"], "region_name": static_attrs["region_name"],
        "site_type": static_attrs["site_type"], "cell_capacity_mbps": static_attrs["cell_capacity_mbps"],
    })
    return features
```

```python
from sklearn.metrics import average_precision_score, precision_recall_curve, mean_absolute_error

from ml_pipeline.config import (
    ARTIFACTS_DIR, CELL_FAULT_FEATURES_NUMERIC, CELL_FAULT_FEATURES_CATEGORICAL,
    CONGESTION_FEATURES_NUMERIC, CONGESTION_FEATURES_CATEGORICAL, CONGESTION_HORIZONS,
)
from ml_pipeline.features import build_batch_cell_fault_features


def encode_categoricals(df, categorical_cols, known_categories=None):
    """One-hot encode with an explicit, saved category list so train/serve encoding
    can never silently diverge (a new category at serve time is safely dropped, not
    a crash or a shifted column)."""
    df = df.copy()
    encoded_cols = []
    categories_used = {}
    for col in categorical_cols:
        cats = known_categories[col] if known_categories else sorted(df[col].dropna().unique().tolist())
        categories_used[col] = cats
        for cat in cats[1:]:  # drop_first equivalent, deterministic ordering
            new_col = f"{col}_{cat}"
            df[new_col] = (df[col] == cat).astype(int)
            encoded_cols.append(new_col)
    return df, encoded_cols, categories_used


def train_cell_fault_model(ml_cell_fault_raw, network_faults, label_col="will_any_fault_next_4h",
                            train_end="2025-03-04", val_end="2025-03-18"):
    """ml_cell_fault_raw: the historical hourly RAN table (pre-feature-engineering) plus
    the label column already attached, as built in the notebook."""
    df = build_batch_cell_fault_features(ml_cell_fault_raw)
    df = df.merge(ml_cell_fault_raw[["cell_id", "timestamp", label_col]], on=["cell_id", "timestamp"], how="left")

    df = df.dropna(subset=["prb_lag_4h", "sinr_change_4h", "bler_change_4h", "sinr_slope_4h", "prb_std_4h"])

    df, encoded_cat_cols, categories = encode_categoricals(df, CELL_FAULT_FEATURES_CATEGORICAL)
    feature_cols = CELL_FAULT_FEATURES_NUMERIC + encoded_cat_cols

    train = df[df.timestamp <= train_end]
    val = df[(df.timestamp > train_end) & (df.timestamp <= val_end)]
    test = df[df.timestamp > val_end]

    X_train, y_train = train[feature_cols], train[label_col]
    X_val, y_val = val[feature_cols], val[label_col]
    X_test, y_test = test[feature_cols], test[label_col]

    pos_weight = (y_train == 0).sum() / max((y_train == 1).sum(), 1)
    model = XGBClassifier(scale_pos_weight=pos_weight, n_estimators=200, max_depth=4,
                           learning_rate=0.05, min_child_weight=5, colsample_bytree=0.8,
                           subsample=0.8, eval_metric="aucpr", random_state=42)
    model.fit(X_train, y_train, eval_set=[(X_val, y_val)], verbose=False)

    val_probs = model.predict_proba(X_val)[:, 1]
    val_prauc = average_precision_score(y_val, val_probs)
    precisions, recalls, thresholds = precision_recall_curve(y_val, val_probs)
    valid_idx = np.where(recalls[:-1] >= 0.7)[0]
    chosen_threshold = float(thresholds[valid_idx[-1]]) if len(valid_idx) else 0.5

    test_probs = model.predict_proba(X_test[feature_cols])[:, 1]
    test_prauc = average_precision_score(y_test, test_probs)

    explainer = shap.TreeExplainer(model)

    ARTIFACTS_DIR.mkdir(parents=True, exist_ok=True)
    joblib.dump(model, ARTIFACTS_DIR / "cell_fault_model.joblib")
    joblib.dump(explainer, ARTIFACTS_DIR / "shap_explainer_cell_fault.joblib")

    schema = {
        "numeric_features": CELL_FAULT_FEATURES_NUMERIC,
        "categorical_features": CELL_FAULT_FEATURES_CATEGORICAL,
        "categories": categories,
        "encoded_feature_order": feature_cols,
        "decision_threshold": chosen_threshold,
    }
    with open(ARTIFACTS_DIR / "cell_fault_schema.json", "w") as f:
        json.dump(schema, f, indent=2)

    metadata = {
        "model": "cell_fault_detector", "val_prauc": val_prauc, "test_prauc": test_prauc,
        "val_base_rate": float(y_val.mean()), "threshold": chosen_threshold,
        "train_rows": len(train), "val_rows": len(val), "test_rows": len(test),
        "note": "Sanitized feature set — excludes availability_mean and region_name, "
                "found to be near-tautological / low-sample-size shortcuts during validation.",
    }
    with open(ARTIFACTS_DIR / "cell_fault_metadata.json", "w") as f:
        json.dump(metadata, f, indent=2)

    print(f"Cell fault model — val PR-AUC: {val_prauc:.4f}, test PR-AUC: {test_prauc:.4f}, "
          f"threshold: {chosen_threshold:.4f}")
    return model, schema, metadata


def train_congestion_models(ml_congestion_forecast, train_end="2025-03-04", val_end="2025-03-18"):
    df = ml_congestion_forecast.copy()
    df, encoded_cat_cols, categories = encode_categoricals(df, CONGESTION_FEATURES_CATEGORICAL)
    feature_cols = CONGESTION_FEATURES_NUMERIC + encoded_cat_cols

    results = {}
    for horizon_label, horizon_hours in CONGESTION_HORIZONS.items():
        target_col = f"prb_t_plus_{horizon_label}"
        other_targets = [f"prb_t_plus_{h}" for h in CONGESTION_HORIZONS if h != horizon_label]
        clean = df.dropna(subset=[target_col, "prb_lag_168h", "prb_slope_7d"]).drop(columns=other_targets)

        train = clean[clean.timestamp <= train_end]
        train = train[train.timestamp <= train.timestamp.max() - pd.Timedelta(hours=horizon_hours)]
        val = clean[(clean.timestamp > train_end) & (clean.timestamp <= val_end)]
        val = val[val.timestamp <= val.timestamp.max() - pd.Timedelta(hours=horizon_hours)]

        model = XGBRegressor(n_estimators=200, max_depth=5, learning_rate=0.05,
                              subsample=0.8, colsample_bytree=0.8, random_state=42)
        model.fit(train[feature_cols], train[target_col])

        val_preds = model.predict(val[feature_cols])
        mae = mean_absolute_error(val[target_col], val_preds)
        naive_mae = mean_absolute_error(val[target_col], val["prb_lag_168h"])

        joblib.dump(model, ARTIFACTS_DIR / f"congestion_model_{horizon_label}.joblib")
        results[horizon_label] = {"mae": mae, "naive_mae": naive_mae,
                                   "improvement_pct": (naive_mae - mae) / naive_mae * 100}
        print(f"Congestion {horizon_label} — MAE: {mae:.3f} vs naive MAE: {naive_mae:.3f} "
              f"({results[horizon_label]['improvement_pct']:.1f}% improvement)")

    schema = {"numeric_features": CONGESTION_FEATURES_NUMERIC,
              "categorical_features": CONGESTION_FEATURES_CATEGORICAL,
              "categories": categories, "encoded_feature_order": feature_cols}
    with open(ARTIFACTS_DIR / "congestion_schema.json", "w") as f:
        json.dump(schema, f, indent=2)
    with open(ARTIFACTS_DIR / "congestion_metadata.json", "w") as f:
        json.dump(results, f, indent=2)
    return results


def build_anomaly_baselines(ml_hourly_ran, metrics=("prb_util_mean", "traffic_mbps_mean", "sinr_mean", "bler_mean"),
                             seasonal_window_weeks=4):
    """Per (cell_id, hour_of_day, day_of_week): trailing seasonal mean/std for each
    metric. Saved as a lookup table the API loads once and queries — no live rolling
    computation needed at serve time for anomaly scoring."""
    df = ml_hourly_ran.copy()
    df["hour_of_day"] = df["timestamp"].dt.hour
    df["day_of_week"] = df["timestamp"].dt.dayofweek

    rows = []
    for (cell_id, hour, dow), group in df.groupby(["cell_id", "hour_of_day", "day_of_week"]):
        group = group.sort_values("timestamp")
        row = {"cell_id": cell_id, "hour_of_day": hour, "day_of_week": dow}
        for m in metrics:
            tail = group[m].tail(seasonal_window_weeks)
            row[f"{m}_expected"] = tail.mean()
            row[f"{m}_std"] = tail.std() if len(tail) >= 2 else np.nan
        rows.append(row)

    baselines = pd.DataFrame(rows)
    baselines.to_parquet(ARTIFACTS_DIR / "anomaly_baselines.parquet", index=False)
    print(f"Saved anomaly baselines: {baselines.shape}")
    return baselines
```

```python
import json
import joblib
import pandas as pd
from functools import lru_cache
from ml_pipeline.config import ARTIFACTS_DIR


class ArtifactStore:
    def __init__(self):
        self.cell_fault_model = joblib.load(ARTIFACTS_DIR / "cell_fault_model.joblib")
        self.cell_fault_explainer = joblib.load(ARTIFACTS_DIR / "shap_explainer_cell_fault.joblib")
        with open(ARTIFACTS_DIR / "cell_fault_schema.json") as f:
            self.cell_fault_schema = json.load(f)
        with open(ARTIFACTS_DIR / "cell_fault_metadata.json") as f:
            self.cell_fault_metadata = json.load(f)

        self.congestion_models = {
            horizon: joblib.load(ARTIFACTS_DIR / f"congestion_model_{horizon}.joblib")
            for horizon in ["1h", "6h", "24h"]
        }
        with open(ARTIFACTS_DIR / "congestion_schema.json") as f:
            self.congestion_schema = json.load(f)

        self.anomaly_baselines = pd.read_parquet(ARTIFACTS_DIR / "anomaly_baselines.parquet")

    def encode_row(self, feature_dict: dict, schema: dict) -> pd.DataFrame:
        """Applies the exact one-hot encoding saved at training time, so an unseen
        category at serve time is safely zero-filled rather than crashing or
        misaligning columns."""
        row = {col: feature_dict.get(col, None) for col in schema["numeric_features"]}
        for col, cats in schema["categories"].items():
            value = feature_dict.get(col)
            for cat in cats[1:]:
                row[f"{col}_{cat}"] = int(value == cat)
        ordered = {c: row.get(c, 0) for c in schema["encoded_feature_order"]}
        return pd.DataFrame([ordered])


@lru_cache(maxsize=1)
def get_artifact_store() -> ArtifactStore:
    return ArtifactStore()
```

```python
import pandas as pd
from fastapi import APIRouter, Depends, HTTPException
from api.schemas import FaultDetectionRequest, FaultDetectionResponse, FaultExplanationResponse, FeatureContribution
from api.dependencies import get_artifact_store, ArtifactStore
from ml_pipeline.features import compute_live_cell_fault_features

router = APIRouter()


def _prepare(request: FaultDetectionRequest, store: ArtifactStore):
    window_df = pd.DataFrame([r.model_dump() for r in request.telemetry_window])
    try:
        feature_dict = compute_live_cell_fault_features(window_df, request.static.model_dump())
    except ValueError as e:
        raise HTTPException(status_code=422, detail=str(e))
    X = store.encode_row(feature_dict, store.cell_fault_schema)
    latest_ts = window_df["timestamp"].max()
    return X, latest_ts


@router.post("/predict/fault/cell", response_model=FaultDetectionResponse)
def predict_cell_fault(request: FaultDetectionRequest, store: ArtifactStore = Depends(get_artifact_store)):
    X, latest_ts = _prepare(request, store)
    prob = float(store.cell_fault_model.predict_proba(X)[:, 1][0])
    threshold = store.cell_fault_schema["decision_threshold"]
    return FaultDetectionResponse(
        cell_id=request.cell_id, timestamp=latest_ts,
        fault_probability=prob, is_fault_flagged=prob >= threshold, threshold_used=threshold,
    )


@router.post("/predict/fault/cell/explain", response_model=FaultExplanationResponse)
def explain_cell_fault(request: FaultDetectionRequest, store: ArtifactStore = Depends(get_artifact_store),
                        top_n: int = 8):
    X, latest_ts = _prepare(request, store)
    prob = float(store.cell_fault_model.predict_proba(X)[:, 1][0])
    threshold = store.cell_fault_schema["decision_threshold"]

    shap_values = store.cell_fault_explainer.shap_values(X)
    row_shap = shap_values[0] if shap_values.ndim == 2 else shap_values
    contributions = sorted(
        [FeatureContribution(feature=col, value=float(X[col].iloc[0]), shap_value=float(val))
         for col, val in zip(X.columns, row_shap)],
        key=lambda c: abs(c.shap_value), reverse=True,
    )[:top_n]

    return FaultExplanationResponse(
        cell_id=request.cell_id, timestamp=latest_ts,
        fault_probability=prob, is_fault_flagged=prob >= threshold, threshold_used=threshold,
        top_contributions=contributions,
    )
```

```python
import pandas as pd
from fastapi import APIRouter, Depends, HTTPException, Query
from api.schemas import CongestionRequest, CongestionResponse
from api.dependencies import get_artifact_store, ArtifactStore
from ml_pipeline.features import compute_live_congestion_features

@router.post("/predict/congestion", response_model=CongestionResponse)
def predict_congestion(request: CongestionRequest,
                        horizon: str = Query("1h", pattern="^(1h|6h|24h)$"),
                        store: ArtifactStore = Depends(get_artifact_store)):

        raise HTTPException(status_code=400, detail=f"Unknown horizon '{horizon}'")

    forecast = float(model.predict(X)[0])
    latest_ts = window_df["timestamp"].max()

    return CongestionResponse(
        cell_id=request.cell_id, timestamp=latest_ts, horizon=horizon,
        forecast_prb_utilization_pct=forecast, history_hours_used=len(window_df),
    )
```

## `api/routers/anomaly.py`

```python
import numpy as np
import pandas as pd
from fastapi import APIRouter, Depends, HTTPException
from api.schemas import AnomalyRequest, AnomalyResponse
from api.dependencies import get_artifact_store, ArtifactStore
from ml_pipeline.config import ANOMALY_Z_THRESHOLD, ANOMALY_PERSISTENCE_HOURS

router = APIRouter()


@router.post("/predict/anomaly", response_model=AnomalyResponse)
def predict_anomaly(request: AnomalyRequest, store: ArtifactStore = Depends(get_artifact_store)):
    values = sorted(request.recent_values, key=lambda v: v.timestamp)
    latest = values[-1]
    latest_ts = pd.Timestamp(latest.timestamp)

    baseline_row = store.anomaly_baselines[
        (store.anomaly_baselines.cell_id == request.cell_id)
        & (store.anomaly_baselines.hour_of_day == latest_ts.hour)
        & (store.anomaly_baselines.day_of_week == latest_ts.dayofweek)
    ]
    if baseline_row.empty:
        return AnomalyResponse(cell_id=request.cell_id, metric_name=request.metric_name,
                                timestamp=latest_ts, actual_value=latest.value,
                                expected_value=None, z_score=None, is_anomaly_flagged=False)

    expected = baseline_row[f"{request.metric_name}_expected"].iloc[0]
    std = baseline_row[f"{request.metric_name}_std"].iloc[0]
    if pd.isna(expected) or pd.isna(std) or std == 0:
        return AnomalyResponse(cell_id=request.cell_id, metric_name=request.metric_name,
                                timestamp=latest_ts, actual_value=latest.value,
                                expected_value=float(expected) if pd.notna(expected) else None,
                                z_score=None, is_anomaly_flagged=False)

    z_scores = [(v.value - expected) / std for v in values[-ANOMALY_PERSISTENCE_HOURS:]]
    breach_streak = all(abs(z) > ANOMALY_Z_THRESHOLD for z in z_scores) and len(z_scores) >= ANOMALY_PERSISTENCE_HOURS

    return AnomalyResponse(
        cell_id=request.cell_id, metric_name=request.metric_name, timestamp=latest_ts,
        actual_value=latest.value, expected_value=float(expected), z_score=float(z_scores[-1]),
        is_anomaly_flagged=breach_streak,
    )
```

## What I could not fully guarantee without running it

I've kept feature names, encoding logic, and column ordering consistent end-to-end (config → features → train → dependencies → routers), but I can't execute this to catch every possible runtime issue. Before trusting it in deployment, run these three checks locally:

1. **Train first, then boot the API** — `artifacts/` must be populated before `api/main.py` can start; a missing file will fail loudly at startup (by design), not silently.
2. **Test one full request through each endpoint with real data pulled from your frozen dataset** (a real cell's last 5-10 hourly rows) before assuming it's correct — particularly `compute_live_cell_fault_features`, since it's the newest, most complex piece and the one most likely to have an off-by-one in the lag/rolling logic when run outside pandas' groupby machinery.
3. **Confirm SHAP's output shape** — `shap.TreeExplainer(...).shap_values(X)` returns a 2D array for binary XGBoost classifiers in most SHAP versions, but this has changed across SHAP releases; the `row_shap = shap_values[0] if shap_values.ndim == 2 else shap_values` line handles both cases, but verify it against your installed `shap` version specifically.

Good catch — that's a real gap in the plan, and the answer changes the project's shape a bit: **the simulator/analytics/feature-engineering pipeline and the API are two independent lifecycles that only meet at one handoff point: the `artifacts/` folder.** Render never runs the generator; it only ever loads what's already in `artifacts/`. Here's how to make that concrete and actually reproducible from a fresh clone.

## Two lifecycles, one handoff

```
LIFECYCLE 1 — Data generation & training (runs once, locally or in Colab)
simulator/  →  data/  (large, git-ignored, regenerable)  →  ml_pipeline/  →  artifacts/ (small, committed)

LIFECYCLE 2 — Serving (runs continuously, on Render)
artifacts/  →  api/  (loads once at startup, never touches simulator/ or data/)
```

`artifacts/` is the only thing Render depends on. It never imports `simulator/`, never generates data, never trains anything. This is why "Render doesn't always have to run from start" is not just possible but the correct design — the API's entire job is to load a handful of small files and serve predictions.

`artifacts/` is **not** ignored — it gets committed. This is the key decision that answers "where does it store": intermediate data lives in `data/` (large, disposable, regenerable, kept off git), but the small trained models/schemas/baselines in `artifacts/` are committed directly to the repo, since they're realistically only a few MB total (a couple of XGBoost joblib files, a SHAP explainer, one parquet baseline table).

## What this means for Render specifically

- Render's `startCommand` (`uvicorn api.main:app ...`) never touches `simulator/`, `ml_pipeline/train.py`, or `data/` — it only runs `api/main.py`, whose startup hook loads whatever is already sitting in `artifacts/` in the deployed repo checkout.
- If `artifacts/` is missing or stale on a given commit, the API will fail loudly at startup (the `joblib.load` calls raise immediately) rather than silently serving a broken model — that's intentional, so a bad deploy is obvious rather than a slow-burning bug.
- To update the live models: run `scripts/run_full_pipeline.py` locally or in Colab, commit the refreshed `artifacts/` files, push, and Render redeploys — it never needs to know the generator or training code exists.

If `artifacts/` ever grows past a few tens of MB (e.g., if `anomaly_baselines.parquet` gets large from tracking many metrics × many cells × hour/day-of-week combinations), committing it to git stops being clean, and you'd want to switch to fetching it from external storage (GCS/Drive) via a small `build.sh` step on Render instead. Good question — worth separating two different things that look similar but aren't: "is this metric realistic to measure" (yes) vs. "is this metric's *relationship to the label* realistic" (no, in this specific simulator). That distinction is the actual answer to whether you should keep these features.

## Why it's not really about real-world legitimacy

You're right that packet loss, latency, and jitter are the real, legitimate signals a NOC uses to detect transport problems — nothing wrong with that category of feature in principle. The issue is narrower: look at the actual generator formulas for a mesh link during a fault (`util` near 0, since idle mesh links normally carry no traffic):

```python
latency = base_lat + 15*np.clip(util-0.93,0,None) + 40*intensity + rng.normal(0, 0.3, N_STEPS)
packet_loss = np.clip(2*np.clip(util-0.97,0,None)**2*100 + 40*intensity, 0, 100)
availability = np.clip(100*(1-intensity), 0, 100)
```

`packet_loss` and `availability` have **zero random noise at all** — they're pure deterministic functions of `intensity`, the exact same variable whose elevation *is* the fault. `latency`/`jitter` have a small noise term, but it's dwarfed by the `40 * intensity` swing. In a real network, packet loss during a link problem is *correlated* with the fault but never perfectly — sensor noise, partial packet loss from congestion vs. hardware vs. fiber-cut each behaving slightly differently, momentary recovery blips, etc. That ambiguity is exactly what makes real detection a non-trivial, generalizable ML problem. Here, there's no ambiguity to learn *through* — the formula is invertible, so any model (even a single-feature threshold) will look "perfect," and that perfection tells you about the generator's cleanliness, not about learned pattern recognition. The cell `availability_mean` issue was the same phenomenon, just easier to spot because it was a single flagrant feature; mesh has the same defect spread across four correlated columns.

So: **don't decide this by asking "is it realistic" — decide it by asking "does the generator add genuine noise/ambiguity to this specific feature's fault-response formula."** If no (packet_loss, availability, and to a lesser extent latency/jitter for mesh), treat it the same way you treated `availability_mean` for cells. If yes (utilization, which is driven by actual routed/failover traffic, not directly by `intensity`), it's a legitimate behavioral feature.

## The answer to your bigger question: report both, don't pick one

This is the professionally correct move, not a compromise — report a **full-feature model** (with the caveat clearly stated: near-perfect score reflects the simulator's deterministic fault-effect formulas, not generalizable pattern learning) alongside a **sanitized model** using only features with genuine stochastic ambiguity. That's a stronger deliverable than picking either alone — it shows you can tell the difference between "the model is smart" and "the data made the target easy," which is a more valuable skill to demonstrate than a single clean number.

```python
def train_mesh_fault_detector(ml_mesh_fault, concurrent_mesh_labels, train_end, val_end):
    df = ml_mesh_fault.merge(concurrent_mesh_labels, on=["link_key", "timestamp"], how="left")
    df["timestamp"] = pd.to_datetime(df["timestamp"])
    df = pd.get_dummies(df, columns=["link_type"], drop_first=True)

    # Near-deterministic proxies of `intensity` — zero/near-zero noise in the generator,
    # so these mechanically restate the fault rather than exhibit a learnable pattern.
    deterministic_proxy_cols = ["packet_loss_mean_pct", "packet_loss_mean_4h",
                                 "latency_mean_ms", "latency_mean_4h", "jitter_mean_ms", "availability_mean"]

    all_features = [c for c in df.columns if c not in
                     ["link_key", "timestamp", "source_agg_id", "target_agg_id", "is_currently_faulted"]]
    sanitized_features = [c for c in all_features if c not in deterministic_proxy_cols]

    train = df[df.timestamp <= train_end]
    val = df[(df.timestamp > train_end) & (df.timestamp <= val_end)]

    def fit_and_score(feature_list, label):
        X_train, y_train = train[feature_list], train["is_currently_faulted"]
        X_val, y_val = val[feature_list], val["is_currently_faulted"]
        print(f"{label} — train faults: {y_train.sum()}, val faults: {y_val.sum()}")
        if y_train.sum() == 0 or y_val.sum() == 0:
            print(f"{label}: insufficient positives for a train/val split — skip modeling, report Cohen's d instead.")
            return None
        pos_weight = (y_train == 0).sum() / (y_train == 1).sum()
        model = XGBClassifier(scale_pos_weight=pos_weight, n_estimators=150, max_depth=4,
                               learning_rate=0.03, min_child_weight=5, colsample_bytree=0.7,
                               subsample=0.8, eval_metric="aucpr", random_state=42)
        model.fit(X_train, y_train, eval_set=[(X_val, y_val)], verbose=False)
        probs = model.predict_proba(X_val)[:, 1]
        prauc = average_precision_score(y_val, probs)
        print(f"{label} PR-AUC: {prauc:.4f} (base rate {y_val.mean():.4f}, "
              f"lift {prauc / (y_val.mean() + 1e-5):.1f}x)")
        return model, prauc

    print("=== FULL-FEATURE MODEL (includes near-deterministic proxies — expect inflated score) ===")
    full_result = fit_and_score(all_features, "Full-feature")

    print("\n=== SANITIZED MODEL (behavioral/utilization signals only) ===")
    sanitized_result = fit_and_score(sanitized_features, "Sanitized")

    return full_result, sanitized_result
```

```python
def audit_core_fault_separation(ml_core_fault):
    ml_core_fault = ml_core_fault.copy()
    ml_core_fault["is_currently_faulted"] = ml_core_fault["will_fault_next_4h"]

    n_pos = ml_core_fault["is_currently_faulted"].sum()
    print(f"Total positive core-fault hours: {n_pos} of {len(ml_core_fault)} "
          f"({ml_core_fault['is_currently_faulted'].mean()*100:.4f}%)")
    print("NOTE: too few positives for any train/val split (temporal OR random) to be "
          "statistically meaningful — reporting full-dataset separation instead.\n")

    feature_cols = ["cpu_mean_pct", "cpu_max_pct", "memory_mean_pct", "memory_max_pct",
                     "session_failure_rate_mean", "alarm_count", "cpu_lag_1h", "cpu_mean_4h",
                     "cpu_change_1h", "session_failure_mean_4h"]  # availability_mean excluded — same tautology risk

    healthy = ml_core_fault[ml_core_fault.is_currently_faulted == 0]
    faulty = ml_core_fault[ml_core_fault.is_currently_faulted == 1]

    records = []
    for col in feature_cols:
        h, f = healthy[col].dropna(), faulty[col].dropna()
        if len(f) == 0:
            continue
        pooled_std = np.sqrt(((len(h)-1)*h.std()**2 + (len(f)-1)*f.std()**2) / (len(h)+len(f)-2))
        d = (f.mean() - h.mean()) / (pooled_std + 1e-5)
        records.append({"feature": col, "healthy_mean": h.mean(), "faulty_mean": f.mean(), "cohens_d": d})

    result = pd.DataFrame(records).sort_values("cohens_d", key=abs, ascending=False)
    print(result.to_string(index=False))
    return result

core_separation = audit_core_fault_separation(ml_core_fault)
```

def audit_fault_magnitude(network_faults, ran_telemetry, transport_telemetry, core_telemetry,
                           sites, cells, aggregations, core_deps_df, mesh_links):
    metric_by_type = {
        "ran_degradation":        ("sinr_db", ran_telemetry, "cell_id"),
        "cell_outage":            ("availability_pct", ran_telemetry, "cell_id"),
        "backhaul_degradation":   ("dl_throughput_mbps", ran_telemetry, "cell_id"),
        "transport_link_failure": ("availability_pct", transport_telemetry, "link"),
        "aggregation_failure":    ("availability_pct", ran_telemetry, "cell_id"),
        "core_degradation":       ("cpu_utilization_pct", core_telemetry, "core_id"),
    }
    rows = []
    for f in network_faults.itertuples():
        if f.fault_type not in metric_by_type:
            continue
        metric, table, key_col = metric_by_type[f.fault_type]
        scope = resolve_fault_scope(f, sites, cells, aggregations, core_deps_df, mesh_links)

        if key_col == "cell_id":
            entities = scope["cells"]
            entity_rows = table[table.cell_id.isin(entities)]
        elif key_col == "core_id":
            entities = scope["cores"]
            entity_rows = table[table.core_id.isin(entities)]
        else:  # transport link: scope["mesh_links"] holds (source, target) tuples
            entities = scope["mesh_links"]
            entity_rows = table[table.apply(lambda r: (r.source_id, r.target_id) in entities or
                                             (r.target_id, r.source_id) in entities, axis=1)]

        if entity_rows.empty:
            rows.append({"fault_id": f.fault_id, "fault_type": f.fault_type, "severity": f.severity,
                         "metric": metric, "n_entities": len(entities), "before": None, "during": None, "delta": "NO SCOPE MATCH"})
            continue

        during = entity_rows[(entity_rows.timestamp >= f.start_time) & (entity_rows.timestamp <= f.end_time)]
        before = entity_rows[entity_rows.timestamp < f.start_time]
        during_mean = during.groupby("timestamp")[metric].mean().mean()
        before_mean = before.groupby("timestamp")[metric].mean().tail(96).mean()

        rows.append({"fault_id": f.fault_id, "fault_type": f.fault_type, "severity": f.severity,
                     "metric": metric, "n_entities": len(entities),
                     "before": round(before_mean, 2), "during": round(during_mean, 2),
                     "delta": round(during_mean - before_mean, 2)})
    return pd.DataFrame(rows)

def build_ml_mesh_fault(ml_hourly_mesh, network_faults, sites, cells, aggregations, core_deps_df, mesh_links, horizon_hours=4):
    df = ml_hourly_mesh.copy()
    df["link_key"] = list(zip(df.source_agg_id, df.target_agg_id))
    df = df.sort_values(["link_key", "timestamp"]).reset_index(drop=True)
    g = df.groupby("link_key")

    df["util_lag_1h"] = g["utilization_mean"].shift(1)
    df["util_mean_4h"] = g["utilization_mean"].transform(lambda s: s.rolling(4, min_periods=1).mean())
    df["util_change_1h"] = df["utilization_mean"] - df["util_lag_1h"]
    df["latency_mean_4h"] = g["latency_mean_ms"].transform(lambda s: s.rolling(4, min_periods=1).mean())
    df["packet_loss_mean_4h"] = g["packet_loss_mean_pct"].transform(lambda s: s.rolling(4, min_periods=1).mean())
    df["hour_of_day"] = df["timestamp"].dt.hour
    df["day_of_week"] = df["timestamp"].dt.dayofweek
    df["is_weekend"] = (df["day_of_week"] >= 5).astype(int)

    labels = []
    for key, group in df.groupby("link_key"):
        pair = key
        matching_faults = network_faults[network_faults.fault_type == "transport_link_failure"]
        starts = [f.start_time for f in matching_faults.itertuples()
                  if (f.link_source_id, f.link_target_id) == pair or (f.link_target_id, f.link_source_id) == pair]
        for t in group["timestamp"]:
            window_end = t + pd.Timedelta(hours=horizon_hours)
            labels.append(int(any(t < s <= window_end for s in starts)))
    df["will_fault_next_4h"] = labels
    return df

ml_mesh_fault = build_ml_mesh_fault(ml_hourly_mesh, network_faults, sites, cells, aggregations, core_deps_df, mesh_links)
def build_ml_core_fault(ml_hourly_core, network_faults, sites, cells, aggregations, core_deps_df, mesh_links, horizon_hours=4):

        for t in group["timestamp"]:

def temporal_split_forward_labels(df, timestamp_col, train_end, val_end, gap_days, horizon_hours):
    train, val, test = temporal_split(df, timestamp_col, train_end, val_end, gap_days)
    # additionally drop rows within `horizon_hours` of each segment's own end,
    # since their label technically depends on data at/after that segment's boundary

    train = train[train[timestamp_col] <= train[timestamp_col].max() - cutoff]
    val = val[val[timestamp_col] <= val[timestamp_col].max() - cutoff]
    return train, val, test

Predictive Layer — Final Table Plan
This is the complete build plan for the three predictive use cases: Fault Prediction, Congestion Forecasting, and Anomaly Detection. It specifies every intermediate and final table, exactly which raw table(s) each column comes from, and the order to build everything in.

0. Ground rules (apply to every table below)
Feature grain is hourly, not 15-minute. Every "hourly" table below is a rollup of the corresponding raw 15-minute telemetry table.
No feature at time t may use data from after t. Rolling windows are always trailing (t-N to t), never centered or forward-looking.
Hidden ground-truth tables (network_faults, data_anomalies, congestion_events) are touched exactly once each, only to build a label/eval table. They are never joined into a feature table.
Split by time, not randomly: e.g. days 1–63 train, 64–77 validation, 78–90 test, with a gap between splits at least as long as your longest rolling window (7 days) so no window straddles a split boundary.
Build in layers, checkpointing after each: raw → hourly → topology join → cross-layer context → feature base → per-use-case final tables → labels/eval. Inspect each layer's output before moving to the next.
1. Hourly Rollup Tables (Layer 1)
Built directly from raw 15-minute telemetry. One row per entity per hour.

5. Use Case 1 — Fault Prediction
Build one table per entity type. Start with ml_cell_fault; extend the same pattern to site/aggregation/mesh/core once validated.

ml_cell_fault
Grain: cell × hour · Source: ml_cell_features (current state) + itself lagged (temporal features) + network_faults (labels only)

Current state (direct copy from ml_cell_features at time t): prb_util_mean, traffic_mbps_mean, throughput_mbps_mean, sinr_mean, bler_mean, drop_rate_mean, availability_mean, handover_success_mean, backhaul_util_mean, core_uplink_util_mean, core_util_mean, upstream_degraded, upstream_down, mesh_failover_active

Lag features (value at t-N): prb_lag_1h, prb_lag_4h, sinr_lag_1h, bler_lag_1h, drop_rate_lag_1h

Trailing rolling features (window ending at t, never including t+): prb_mean_4h, prb_std_4h, sinr_mean_4h, sinr_slope_4h (linear regression slope of SINR over trailing 4h — captures a developing decline, not just level), bler_mean_4h, drop_rate_mean_4h, availability_mean_4h

Delta features: prb_change_1h = prb_util_mean[t] - prb_util_mean[t-1h] sinr_change_4h = sinr_mean[t] - sinr_mean[t-4h] bler_change_4h = bler_mean[t] - bler_mean[t-4h]

Alarm history: alarm_count_trailing_24h (sum of ml_hourly_ran.alarm_count over trailing 24h), hours_since_last_alarm

Calendar: hour_of_day, day_of_week, is_weekend

Static: technology, band, site_type, region_name, cell_capacity_mbps

Labels (built from network_faults via resolve_fault_scope — never used as features):

Column	Meaning
will_direct_fault_next_4h	1 if a fault whose entity_id IS this cell (ran_degradation, cell_outage) starts in (t, t+4h]
will_cascaded_fault_next_4h	1 if this cell falls in resolve_fault_scope of an aggregation_failure/core_degradation/backhaul_degradation fault starting in (t, t+4h]
will_any_fault_next_4h	will_direct_fault_next_4h OR will_cascaded_fault_next_4h — primary training target
fault_type_if_any	For error analysis only — never a feature
ml_mesh_fault, ml_core_fault, ml_aggregation_fault
Same pattern as ml_cell_fault, built from ml_hourly_mesh/ml_hourly_core/aggregation-level rollup respectively, with entity-appropriate current-state/lag/rolling columns (e.g. ml_core_fault uses cpu_mean_pct, session_failure_rate_mean instead of SINR/BLER). Build after ml_cell_fault is validated.

6. Use Case 2 — Congestion Forecasting
ml_congestion_forecast
Grain: cell × hour · Source: ml_cell_features (current + lagged) — labels are the entity's own future value, not from any hidden table

Lags: prb_lag_1h, prb_lag_2h, prb_lag_24h (same hour yesterday), prb_lag_168h (same hour last week), traffic_lag_1h, traffic_lag_24h

Rolling: prb_mean_24h, prb_std_24h, prb_mean_7d, prb_slope_7d (14-day trend, captures the generator's long-term drift), traffic_mean_24h, traffic_slope_7d

Labels (the cell's own actual future value — no hidden table involved): prb_t_plus_1h, prb_t_plus_6h, prb_t_plus_24h — train one model per horizon; never include a different horizon's target as a feature for another model.

7. Use Case 3 — Anomaly Detection
ml_anomaly_features
Grain: cell × hour · Source: ml_cell_features + a seasonal baseline computed from the entity's own history

For each of prb_util_mean, traffic_mbps_mean, throughput_mbps_mean, sinr_mean, bler_mean:

{metric}_expected — trailing seasonal baseline (e.g. mean of this cell's own value at the same hour-of-day/day-of-week over prior weeks, or an exponentially weighted trailing average)
{metric}_residual = actual - expected
{metric}_zscore = residual / rolling_std_of_residual
anomaly_scores (detector output, not a feature table)
Grain: cell × hour — entity_id, timestamp, metric_name, actual_value, expected_value, residual, z_score, is_anomaly_flagged (1 if |z_score| exceeds threshold for ≥2 consecutive hours)

8. Evaluation / Ground-Truth Tables (never joined into features)
eval_fault_events
From network_faults + resolve_fault_scope: entity_id, entity_type, fault_id, fault_type, severity, start_time, end_time

eval_congestion_events
From congestion_events directly (matches its real schema — no invented severity field): congestion_id, site_id, start_time, end_time, peak_multiplier, design_util_baseline

eval_data_anomalies
From data_anomalies directly: anomaly_id, cell_id, start_time, end_time, multiplier

anomaly_evaluation (three-way scoring harness)
Grain: cell × hour — joins anomaly_scores.is_anomaly_flagged against all three eval tables above via time-window membership, producing ground_truth_fault, ground_truth_congestion, ground_truth_data_anomaly, ground_truth_category (priority-ordered if windows overlap: fault > congestion > anomaly — document this tie-break), and detector_correct. This is where you produce the three-way confusion matrix showing whether the detector (and, later, which features) actually distinguish the three phenomena or just flag "something's unusual" indiscriminately.

9. Build Order
ml_hourly_ran, ml_hourly_backhaul, ml_hourly_mesh, ml_hourly_core_uplink, ml_hourly_core — validate row counts and spot-check a few entities against raw telemetry before proceeding.
ml_entity_dependencies — validate every cell resolves to exactly one site/aggregation/primary core/secondary core, no orphans.
ml_hourly_network_context — validate mesh_failover_active actually turns on during known fault windows that force failover (cross-check a couple manually against network_faults).
ml_cell_features — row count should equal n_cells × n_hours exactly; check for unexpected nulls.
Fault labels (will_direct_fault_next_4h etc.) — validate against the same fault-magnitude style audit used earlier in this project (does the positive-label rate roughly match expected fault-affected hours from network_faults).
ml_cell_fault full feature set — check no column reads data from t+.
ml_congestion_forecast — validate lag/rolling columns manually on 2–3 cells against the raw hourly series.
ml_anomaly_features + anomaly_scores + anomaly_evaluation — build last, since it depends on having validated rolling/seasonal logic already proven correct in steps 6–7.
Apply the temporal train/val/test split only after all tables are built and validated — splitting early risks accidentally computing a rolling window across the boundary during debugging.
Do not skip the per-layer validation steps — every earlier stage of this project (topology, capacity, telemetry) turned up a real bug exactly when a layer was trusted without checking it first.
